# Mentoria Hub

Образовательная платформа для учеников 8–11 классов: каталог конкурсов, олимпиад, стипендий и стажировок + асинхронные курсы по школьным и поступительным предметам.

## Возможности

- 🏆 Каталог возможностей с фильтрами по категории, формату и классу
- 📚 Курсы (математика, английский, физика, биология, экономика, информатика, подготовка к SAT/IELTS)
- 📊 Личный кабинет: прогресс по курсам, сохранённые возможности, ближайшие дедлайны
- 🛠️ Админ-панель для добавления и редактирования курсов и возможностей
- 🌍 Интерфейс на русском языке, ориентирован на учеников Казахстана и других стран

## Технологии

HTML, CSS, JavaScript (без фреймворков и зависимостей)

## Как запустить

Просто открыть `index.html` в браузере - сервер не требуется.
